# Typography

## Typeface choice
Classes: serif (traditional/classic), sans serif (neutral/modern, most legible at all sizes), script (handwriting — large only), display (decorative — large only), monospaced (code, comparing numbers).

**Default: one sans-serif typeface** — legibility, neutrality (fits any brand, content stays the focus), simplicity.

Picking one:
- popular and well-tested; many weights (light→bold); tall x-height and roomy letter spacing for small sizes; supports needed languages; OpenType features.
- borrow from well-designed products; when in doubt use the platform system font.

**Optional second typeface for headings only** to add personality:
- sans → neutral/minimal/modern · serif → established/classic · rounded sans → fun/soft · casual script → personal/handmade · formal script → elegant · light sans → chic/luxury.

## Weights
Regular + bold only (semibold if bold is too heavy). Bold for headings, regular elsewhere. Very thin/heavy weights only at large sizes.

## Type scale
Base body size × ratio, repeatedly; round to whole numbers.
Ratios: 1.067 Minor Second · 1.125 Major Second · 1.200 Minor Third · 1.250 Major Third · 1.333 Perfect Fourth · 1.414 Augmented Fourth · 1.500 Perfect Fifth · 1.618 Golden.
- Small ratios → dense apps, tools, dashboards. Large ratios → marketing sites.
- Use a smaller ratio on mobile so headings don't wrap badly.
- Example (18 × 1.250): 44 / 36 / 28 / 22 bold headings, 18 body, 15 small.
- Don't create text styles you don't need.

## Size
Long body text ≥ **18px** (read at arm's length on every device).

## Line height
- Long body text **≥1.5** (1.5–2 works). Longer lines, darker/heavier faces, and faces that look large need more.
- Decrease line height as size grows (e.g. 18px @1.6, 24px heading @1.3) so the visual gap between lines stays consistent.

## Line length
**40–80 characters** per line incl. spaces. Don't let paragraphs span the full page width; constrain the text block and align it left or centre.

## Alignment
Left-align (F-pattern reading). No centred long text (ragged start), no justified text (uneven spacing, "rivers", harder for dyslexia). Don't mix alignments.

## Letter spacing
Tighten letter spacing on large headings for text faces (more as size grows); display faces usually need nothing.

## Text on photos
Must still meet 4.5:1 (small) / 3:1 (large). Techniques: bottom-up linear gradient (darkest colour ~90% → 0% at half height) + subtle text shadow; flat darkest-colour overlay ~50% + text shadow; blur the background; solid text background (caption style).

## Text colour
No light-grey body text (fails 4.5:1). No pure black on white (eye strain) — use an accessible dark grey.

## UPPERCASE labels (see copywriting)
Only short labels: small size, bold, extra letter spacing (e.g. 14px bold +2px).

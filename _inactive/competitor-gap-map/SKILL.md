# Competitor Gap Map

A feature-comparison spreadsheet is not analysis — it's bookkeeping.
A gap map asks one question: **on the axes that matter to the buyer,
where is there empty space large enough to stand in?**

## Step 1 — Define the buyer-mattering axes (not feature axes)

The wrong axes:
- "Has reviews", "has maps", "has mobile app" (feature checklist)

The right axes (examples):
- **Trust** — how confident is a first-time visitor that a listing /
  review is real?
- **Local depth** — how complete is the listing in *this specific city*?
- **Language fit** — does the product work in the buyer's actual
  language(s)?
- **Recency** — when was data last verified?
- **Coverage breadth** vs **coverage depth** (tradeoff axis)

Pick **2 axes** for the headline 2x2. Save the rest for the detailed
grid.

## Step 2 — Inventory the alternatives

Include:
- Direct competitors (named products)
- Adjacent products that solve part of the job
- Manual workarounds (Facebook groups, asking friends, Google search)
- Status quo / doing nothing

Aim for 7-12 entries. If you have 3, you've under-researched.

## Step 3 — Score each on every axis

Use a simple 1-5 scale. Be **fair to competitors** — overstating their
weakness leads to losing decks. Underrate yourself by default; you have
recency bias.

Sources for scoring:
- Use the product (sign up, search 5 real queries)
- Read recent reviews (App Store, Play Store, Reddit, Facebook)
- Check the most active community channel for the category
- Note: count *missing* features as 0, but only score features the
  buyer asked for

## Step 4 — Plot the 2x2 and look for empty quadrants

The wedge is an **empty quadrant** where the buyer-mattering value is
high but no competitor occupies it. If every quadrant is crowded, your
axes are wrong — re-pick.

If the empty quadrant exists but no buyer asks for it, it's not a
wedge — it's a "nobody wants this" zone. Validate demand before
committing.

## Step 5 — Translate the gap into a wedge statement

```
The market currently forces a tradeoff between [axis A] and [axis B].
[Existing players] sit in [crowded quadrant].
We will sit in [empty quadrant] by [specific mechanism],
which is defensible because [why competitors can't / won't follow].
```

Defensibility candidates (pick at least one):
- **Operational moat** — sustained human labor competitors won't fund
  (e.g., human verification)
- **Network density in a niche** — winner-take-most in a small geography
- **Data moat** — exclusive, recurring, hard-to-replicate data source
- **Distribution moat** — owned channel competitors can't access
  (community, diaspora, religious institution, govt partnership)
- **Trust moat** — reputation that takes years to build

"Better UX" is **not** a moat. "We care more" is **not** a moat.

## Step 6 — Stress-test the wedge

Ask:
1. If the largest competitor copied this tomorrow, what stops them?
2. If they don't copy it, why? (If "they're lazy" — assume they're not.)
3. Would a savvy buyer pay a premium for the wedge value? If no, it's
   a feature not a wedge.

If the wedge survives all 3, write the final output.

## Output

1. **Buyer-mattering axes** (with rationale, ≤2 paragraphs)
2. **Competitor inventory table** with scores on all axes
3. **2x2 chart** (markdown or ASCII) showing crowding
4. **Wedge statement** (the template above)
5. **3 risks** that could collapse the wedge in 12 months
